AI Agents
Three-Tier Agentic Pipeline
Tier 1  ·  Monitor Agent
"Run Monitor Agent" button
  • Input: 15 KPI values from /api/kpis
  • Temp: 0.2 (structured JSON)
  • Output: JSON alert array → kpi_id, severity, message, recommendation
  • Writes: workspace.otm.dq_alerts
  • Dedup: skips KPIs already in Open state
  • Fallback: FALLBACK_MESSAGES dict
→
Tier 2  ·  Root-Cause Agent
"Explain" button on alert
  • Input: ≤20 failing rows from /api/drilldown
  • Temp: 0.2 (structured JSON)
  • Output: root_cause, pattern, affected_count, suggested_action, suggested_sql
  • Updates: alert status → 'In Review'
  • Fallback: FALLBACK_ANALYSES dict (JI02, CS07, CS02, RI01, RI05, BIZ02, BIZ03)
→
Tier 3  ·  Remediation Agent
"Generate Fix" → "Apply Fix"
  • Draft: approve=false → SQL shown, not executed
  • Execute: approve=true → SQL runs on Databricks
  • Temp: 0.2 → sql, risk_level, rows_affected_estimate
  • Safety: blocks DROP · TRUNCATE · ALTER · DELETE without WHERE
  • Post-fix: KPI recompute + POST /api/snapshot + card → GREEN
  • Fallback: suggested_sql from root-cause analysis
Supporting Agents
Summary Agent
  • Trigger: every page load & "Regenerate" button
  • Input: full 15-KPI JSON payload
  • Temp: 0.3 (natural language narrative)
  • Output: 3-4 sentence executive summary string
  • Fallback: _fallback_summary() — rule-based from worst/best KPI
Chat Agent
  • Trigger: user message in chat panel
  • Input: question + KPI snapshot + alert history + last 5 conversation turns
  • Temp: 0.3 (natural language)
  • Output: reply string + cited_kpis list (triggers card pulse animation)
  • Fallback: _fallback_reply() keyword-matching (ghost, orphan, fix, trend…)

Bob Client
Strategy 1 — Bob Shell Subprocess  (preferred)
  • Command: bob --auth-method api-key --instance-id … --team-id … --yolo --hide-intermediary-output -p "…"
  • Key: BOB_API_KEY from .env → passed as subprocess env var
  • Bob Shell handles: VPN routing, BFF token exchange, ANSI cleanup
  • Prompt: [SYSTEM INSTRUCTIONS] preamble + [USER REQUEST] combined string
  • Timeout: 90 s (BOB_SHELL_TIMEOUT env var)
  • Retries: 3× with exponential backoff (2 s · 4 s · 6 s)
  • Skip: if bob binary not found → jumps to Strategy 2 immediately

Strategy 2 — Direct HTTP  (fallback)
  • URL: POST https://api.us-east.bob.ibm.com/inference/v1/chat/completions
  • Model: openai/gpt-oss-20b
  • Auth A — API key: Authorization: Apikey <BOB_API_KEY>
  • Auth B — OAuth: Bearer token DPAPI-decrypted from Bob IDE SQLite store (valid ~24 h)
  • User-Agent: bobshell/1.0.6  — required to pass Cloudflare WAF on /inference/v1/
  • Headers: Content-Type: application/json · x-instance-id · x-team-id
  • Payload: { model, temperature, messages: [{role:system}, {role:user}] }
  • Response: choices[0].message.content
  • Retries: 3× per auth method with 2 s backoff
