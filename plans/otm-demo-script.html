"This is the Transport Analytics AI-Powered Data Quality Platform — built on IBM Bob for the IBM watsonx Challenge 2026. Transport Analytics is the logistics backbone for major supply chains. Step 6a — Explain Root Cause

Scroll to the CS-07 alert (Ghost Mapping) — this is the star KPI. Click "Explain root cause"
"Now Bob fetches the actual 3 failing records from Databricks and analyses them. It's not pattern-matching on the KPI percentage — it's reading the actual data rows. It identifies that these 3 orders each have two active ORDER_SHIPMENT rows pointing to different shipments — a CDC delete event that never propagated from Transport Analytics to the data lake."
Root-cause appears inline inside the alert card: yellow "What this means in plain English" box, green "Recommended next step" box. The alert status changes from "Open" to "In Review" in Databricks.

Step 6b — Generate Fix (Draft)

Click: "Generate fix (AI draft)" on the CS-07 alert
"Bob drafts a corrective SQL statement. It shows you the exact SQL, labels the risk level — LOW in this case — and estimates how many rows it will affect. Critically, nothing has been executed yet. The human is still in control."
Point to the SQL block: UPDATE workspace.otm.order_shipment SET lake_status = 'STALE' WHERE otm_deleted = 'YES' AND lake_status = 'Active'
"This is a targeted UPDATE — it only touches the 3 stale rows. No DROP, no TRUNCATE, no blind DELETE. The platform's safety guard would block any SQL that doesn't meet these criteria before it ever reaches Databricks."

Step 6c — Approve & Apply

Click: "Approve & Apply" → confirm in the dialog
Watch the CS-07 KPI card
"One confirmation click. The SQL runs on Databricks. The KPI recomputes live. Watch the CS-07 card — it pulses and turns green. A new Post-fix data point appears on the Consistency sparkline. The entire cycle — detect, explain, draft, approve, verify — in under 60 seconds. Previously 4 to 8 hours of DBA time."
After applying, the kpi_snapshots table gains a new "Post-fix" row. The sparkline re-renders automatically. The CS-07 card glows green for 6 seconds via the ai-fixed CSS animation.
